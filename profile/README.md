# Plainview-Old Bethpage Soccer Club

**Promoting and developing youth soccer in Plainview-Old Bethpage since 1974.**

POBSC is a 501(c)(3) non-profit serving over 1,450 players across intramural, travel, and TOPSoccer programs on Long Island, New York.
